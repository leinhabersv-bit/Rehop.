# Claims and limitations

**Allowed:** “Working simulation of a multi-provider pickup-recovery agent”, “Backend-generated rider telemetry events”, “Deterministic policy enforcement”, and “Evaluated on synthetic scenarios”, when supported by passing tests and output.

**Not allowed:** Real Uber/Ola/Rapido/RedTaxi booking, real driver monitoring, actual price comparisons, guaranteed pickup, real-world failure probability, driver intent, real money/time saved, or real provider integration.

The simulation is not evidence of actual provider reliability. The safety mechanism must be reviewed again if commercial APIs ever become available.
