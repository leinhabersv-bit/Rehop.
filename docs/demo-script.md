# Three-minute judge demo (suggestion)

1. **0:00–0:25 — Pain:** Accepted driver isn't arriving; passengers repeatedly open multiple cab apps.
2. **0:25–0:50 — Setup:** Show route, fare cap, maximum retries, opt-in recovery. Highlight all fares/positions are synthetic.
3. **0:50–1:35 — Stall, not yet cancelled:** Start S03, advance clock to risk HIGH, show evidence and a backup proposal; no automatic cancellation.
4. **1:35–2:05 — Safe change:** Approve switch; show old ride cancellation confirmed before replacement.
5. **2:05–2:30 — Second cancellation:** Start S05 and advance. Show bounded auto-recovery to a third provider.
6. **2:30–2:45 — Negative test:** S02 temporary traffic stop: no unnecessary switch.
7. **2:45–3:00 — Proof:** Show pytest and eval smoke report, then acknowledge partner-API deployment constraint.

Do not claim these demo cases represent real rider data or real-world performance.
